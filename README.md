# Simple Console Library Management System in Java

A lightweight, OOP-based console application written in Java that manages student and faculty authentication, course/department selection, and library book issuance.

## 🚀 Features
- **Abstract Base Classes**: Enforces authentication blueprints via `LoginStudent` and `LoginFaculty`.
- **Role-Based Workflows**: Separate login and execution flows for **Student** and **Faculty** roles.
- **Dynamic Book Inputting**: Input processing for dynamic book quantities using arrays.
- **Department/Course Selection**: Interactive console menu handling using `switch` expressions.
